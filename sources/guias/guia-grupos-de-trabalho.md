# Guia de grupos de trabalho do CAEX

DADOS FICTÍCIOS. Documento criado para demonstração.
Versão de 01/02/2030.

1. Todo grupo de trabalho precisa de ao menos 3 integrantes.
2. A proposta deve informar objetivo, coordenação do grupo e prazo.
3. A gestão registra a criação em ata.
4. O grupo encerra as atividades com um relatório.
